# Oxidase v0.1 prototype

The v0.1 code at public baseline `cb9e86a` modeled `Static`, `Forward`, and `Router`
as privileged handlers. It established useful typed Pattern placeholders, template
filter experiments, import examples, and routing tests. Those semantics are test
inputs for v0.2, not a compatibility contract.

Known architectural risks include fully buffered proxy bodies, a client constructed
per request, blocking file reads on async workers, shared capture mutation,
unordered query reconstruction, shallow validate-only behavior, incorrect TLS-file
validation, lexical-only static path checks, restart-by-task-abort reload, and
request metadata inferred from origin-form URIs.

The v0.2 workspace replaces the executable implementation. Git history retains the
prototype for migration work.
